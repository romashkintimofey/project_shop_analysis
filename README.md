**# Анализ данных интернет-магазина подарков**



**Проект посвящён исследовательскому анализу данных онлайн-магазина подарков.**

**В ноутбуке выполнены предобработка и очистка данных, объединение таблиц, разведочный анализ, расчёт бизнес-метрик и проверка статистических гипотез.**



**## Что сделано**



**- предобработка данных: работа с пропусками, дубликатами, некорректными значениями и выбросами;**

**- объединение основной таблицы заказов со справочником товаров;**

**- разведочный анализ: распределения, выручка по кластерам и странам, активность по дням недели и часам;**

**- расчёт метрик: DAU, MAU, sticky factor, средняя выручка на клиента;**

**- профилирование клиентов: возвратные и невозвратные покупатели;**

**- RFM-сегментация клиентов и анализ сегментов;**

**- проверка статистических гипотез о долях, средних чеках и количестве заказов.**
